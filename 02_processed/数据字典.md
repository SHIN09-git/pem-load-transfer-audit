# 跨负载诊断数据字典

固定来源：Zenodo 19361280。所有气体数值采用原作者稀释校正列，单位为 vol.%；绝对误差的单位为 vol.% 点。1 vol.% 点相当于 10000 ppm 体积分数。

## 原始层与派生层

`gc_observations.csv` 保留全部 119198 行非空校正 GC 值；不前向填充、不按数值相等去重。`source_row` 是 CSV 中非空数据记录的一基序号，不包括表头和空行。`segment_id` 根据实际顺序中测量类型或计数变化建立，跨分块连续。

`stages.csv` 保留所有实际操作段的起止时间、行数、GC 数和原始行边界。`ocv_observations.csv` 保留全部 OCV 电压记录。重复电气时间戳可以来自高频采样时间取整，不视为倒序，也不强行删除。

`characterization_tails.csv` 包含 4 个 MEA × 8 轮 × 7 个负载 × 2 个窗口，共 448 行。实际电流除以 4000 换算为 A/cm²，再匹配最近的规定负载；最大匹配偏差小于 0.03 A/cm²。

`cycles.csv` 含每窗口 547 个可配对周期，两窗口共 1094 行。每个高载段之后寻找下一低载段，不能跨越另一个高载、表征、OCV 或电压循环段。5 个没有高载 GC 的周期在排除表单列。

## 周期字段及可用时点

| 字段 | 含义及单位 | 预测时可用 |
|---|---|---|
| mea、batch、cycle | MEA、并行批次、原高载类型计数 | 是 |
| window_min | GC 尾窗 30 或 60 分钟 | 是 |
| forecast_h | 高载操作段最后电气记录时间，小时 | 是，作为阶段结束近似 |
| time_h | 最后高载 GC 观测时间，小时 | 是，时间模型输入 |
| high_h2 | 以最后高载 GC 为锚点向前取窗口，中位浓度 | 是 |
| high_tail_slope | 高载尾窗 OLS 斜率，vol.% 点每小时 | 是 |
| high_tail_n、high_n_gc | 尾窗观测数与高载总 GC 数 | 是 |
| high_first_gc_h、high_last_gc_h | 高载实际 GC 起止时间 | 是 |
| high_tail_cutoff_h、high_tail_first_h | 窗口理论截点与窗口第一个实际 GC 时间 | 是 |
| high_duration_h、high_gc_span_h | 电气阶段长度与 GC 观测跨度 | 是，不能混称 |
| high_gc_staleness_h | 高载末 GC 到预测发出时的间隔 | 是 |
| high_temp_C、high_pressure_bar | 高载 GC 尾窗同步温压中位数 | 是；温度是块体温度 |
| early_h2、high_drop | 高载第 5–35 分钟中位值及与尾值之差 | 是 |
| ocv_end_V、ocv_drop_V | 最近已发生 OCV 的尾 10 秒电压中位数、前 2 秒至尾段之差 | 是 |
| pre_ocv_wait_h、ocv_age_h | 上次 OCV 结束至高载开始、至预测时点的时间 | 是 |
| ocv_current_protocol | OCV 结束到高载开始小于 60 秒 | 是；用于历史敏感性 |
| exp_c、exp_tau_h | 单指数族下拟合渐近浓度及时间尺度 | 是；不等于物理真值 |
| exp_identifiable | 启发式 SSE 剖面判据是否通过 | 是；不是统计检验或物理证明 |
| target、low_h2 | 随后低载的 GC 尾窗中位浓度 | 否，评价标签 |
| low_start_h、low_end_h、low_last_gc_h | 随后低载的实际起止和最后 GC 时点 | 否，不进入预测器 |
| low_temp_C、low_pressure_bar、low_duration_h | 随后低载实测温压及保持长度 | 否，仅回顾性质量检查 |
| lag_gc_h | 低载末 GC 与高载末 GC 的时间差 | 否，仅描述 |

## 模型输出

`frozen_predictions.csv` 为冻结模型的逐周期预测。`online_predictions.csv` 增加 `is_calibration`、`n_initial`、`n_revealed_before`、`max_label_end_h`，可审核某次预测前到底开放了多少标签。每次先计算所有模型预测，再揭示当前周期的校准标签。最近 8 个标签模型只保留已开放标签的末 8 个；初始可用标签仍与其他模型相同。

`is_eval` 标识主要后期区间；在训练结束至评价开始之间，在线模型可以按固定日程获取标签，其消耗计入预算。评分中 `non_calibration` 排除当轮将被揭示的周期；`all_predictions` 包含其揭示前预测，作为附加检查。不同周期预算的直接比较另提供共同未校准周期结果。

`high_quality` 仅利用高载已知量。`both_quality` 还使用随后低载实测量，只能用于回顾性敏感性。质量检查不改变主分析训练集；OCV 子集敏感性单独在筛选后的训练集重拟合。
