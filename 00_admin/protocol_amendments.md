# 分析补充记录

本项目是既有数据的探索性再分析，不是预注册验证。

2026-10-12，在首轮冻结模型计算后，发现 Pt/C 和 Reference 各有 5 个周期没有紧接在高载前的 OCV 阶段。追加 `history_sensitivity.py`：排除这些周期后重新校准和评价；另外比较时间加高载加已发生等待时长、时间加高载加近期 OCV 指示变量。它们是后续敏感性检查，不替代原主分析。

首轮计算还发现原报告 28 个训练周期来自按低载终点时间切分。`proposal_reproduction.py` 单独复现原口径；本阶段主分析坚持使用预测时已知的高载时间形成时间区间，含 27 个训练周期。两种切分均保留，不混报数值。

动态曲线的 SSE 剖面判据固定于初始分析方案。随后追加从 30 与 60 分钟起拟合，以评价模型形状敏感性；不使用此结果调优主预测器。标记为“可辨识”仅指指定单指数族内的启发式残差剖面判据通过，不能等同于物理参数可辨识或统计置信区间。
